# Thomas Boren — Portfolio

Static site (HTML + CSS, no build step).

- `index.html` main page
- `about.html` About page
- `projects/ai-implementation.html` project page
- `links.html` mobile Linktree-style page (for QR codes / NFC)
- `css/style.css` all styling; colors are variables at the top
- `assets/` favicon, social preview image, contact card (.vcf)

**Try the white theme:** add `class="theme-light"` to the `<body>` tag on each page.
**Add a project:** copy `projects/ai-implementation.html`, edit it, and add a new `<article class="project">` block on `index.html`.
